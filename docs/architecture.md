# 架构说明: 小型文件归档解决方案

## 1. 方案概述

本解决方案用于将大量小型文件高效归档到对象存储，并通过清单文件实现单个文件的快速恢复。

## 2. 架构设计

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户环境                                 │
│                                                                 │
│  ┌──────────────┐    ┌────────────────┐    ┌───────────────┐  │
│  │ 文件源目录    │───>│ 归档器脚本     │───>│ OBS 存储     │  │
│  │ (源路径)     │    │ (多进程 tar)   │    │ (tar 文件)   │  │
│  └──────────────┘    └───────┬────────┘    └──────▲───────┘  │
│                              │                      │           │
│                              ▼                      │           │
│                     ┌────────────────┐              │           │
│                     │ JSON 清单文件  │──────────────┘           │
│                     │ (OBS 存储)     │                        │
│                     └────────────────┘                        │
│                              ▲                                │
│                              │                                │
│  ┌──────────────┐          │                                │
│  │ 恢复脚本     │──────────┘                                │
│  │ (单文件恢复) │                                           │
│  └──────────────┘                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                        华为云资源                                │
│                                                                 │
│  ┌──────────────┐    ┌────────────────────────────────────┐   │
│  │ OBS          │    │ 归档器 IAM 委托                     │   │
│  │ (tar + 清单) │    │ (读取源文件 + 写入 OBS)           │   │
│  └──────────────┘    └────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心组件

| 组件 | 说明 |
|------|------|
| **归档器** | 多进程 Python 脚本，将小文件打包成 tar 并上传到 OBS |
| **清单管理器** | 记录每个文件的 tar 路径、字节偏移、MD5 等信息到 JSON |
| **恢复器** | 根据清单定位并提取单个文件 |

## 3. 数据流程

### 3.1 归档流程

```
1. 扫描源目录
   └─> 多线程枚举文件，生成文件列表

2. 分批构建 tar
   └─> ProcessPoolExecutor 并行构建 tar 对象
   └─> 每个 tar 设置固定大小 (如 20MB)

3. 上传到 OBS
   └─> 分片上传大文件
   └─> 记录每个文件的元信息

4. 生成清单
   └─> 收集所有文件的元信息
   └─> 写入 JSON 文件到 OBS
```

### 3.2 恢复流程

```
1. 读取清单文件
   └─> 从 OBS 下载 JSON 清单

2. 定位文件
   └─> 根据文件名查找 tar 路径和字节范围

3. 提取文件
   └─> 使用字节范围 GET 从 tar 中提取
   └─> 验证 MD5
```

## 4. 技术细节

### 4.1 tar 打包策略

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| tar 大小 | 20 MB | 平衡请求数和单个文件大小 |
| 工作进程 | CPU 核数 | 并行构建 tar |
| 扫描线程 | 8 | 并行枚举源文件 |

### 4.2 清单格式

```json
{
  "version": "1.0",
  "archive_date": "2026-08-21T10:00:00Z",
  "source_path": "/data/files",
  "files": [
    {
      "filename": "subdir/doc1.txt",
      "tar_key": "archive/20260821/archive_001_00001.tar",
      "offset": 0,
      "length": 1024,
      "md5": "<file-md5-checksum>"
    }
  ]
}
```

### 4.3 OBS 存储布局

```
<bucket>/
└── <prefix>/
    └── <date>/
        ├── archive_001_00001.tar
        ├── archive_001_00002.tar
        └── ...
```

## 5. 限制说明

- **无事务支持**: JSON 清单不支持事务，多进程写入需外部同步
- **无时间旅行**: 无法像 Iceberg 那样查看历史版本
- **手动压缩**: 需要定期手动合并小 tar 文件
